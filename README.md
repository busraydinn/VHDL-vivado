# 📌 VHDL Öğrenme Projeleri (Vivado)

Bu repository, **Xilinx Vivado** kullanarak VHDL ile geliştirdiğim dijital tasarım modüllerini içermektedir.  
Amacım öğrenme sürecimi dokümante etmek ve tekrar kullanılabilir bir RTL tasarım arşivi oluşturmaktır.

---

## 🛠 Kullanılan Araçlar

- **Donanım Tanımlama Dili:** VHDL
- **Geliştirme Ortamı:** Xilinx Vivado
- **Simülasyon Aracı:** Vivado Simulator


---

## 📂 Proje Yapısı Şuan İçin : 

```
.
├── UART_TX/

│   ├── uart_tx_tb.vhd

```

## 🎯 Bu Repository'nin Amacı

- VHDL ile RTL tasarım pratiği yapmak
- FSM tasarımını geliştirmek
- UART protokolünü detaylı anlamak
- FPGA tasarım portföyü oluşturmak
- Gömülü donanım sistemleri için altyapı oluşturmak
